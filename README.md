# nimsforestmastery

Role mastery paths for humans and AI agents. One mastery path per nim,
generated live from the artifacts that already run the nim.

The nimsforest org instance is neoportal at developer.nimsforest.com.

Design: nimsforest2/docs/architecture/ROLE_MASTERY.md. Issues #309 (MASTER), #312 (this service), #302 (tracking) on issues.nimsforest.mynimsforest.com.

This repo holds no role content and no credentials. Role pages and
bundles render at request time from the org's own Soil.
